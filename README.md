# Dotfusion plugins for Claude

Public plugins from [Dotfusion](https://dotfusion.com), a 27-year-old B Corp in Toronto that migrates enterprises off AEM, Sitecore and WordPress onto composable platforms.

| Plugin | What it does |
| --- | --- |
| [Content Migration Audit](./content-equity-pre-audit) | Scores every page on a site and assigns a migration verb: keep, consolidate, rewrite, redirect, retire or create. |

Each plugin lives in its own folder and is submitted to the Claude directory separately. MIT licensed.
